# Deprecated Prompt Wrappers

`PROMPT-XXX.md` files were removed because each implementation task has a one-to-one task file.

Use the task file directly:

```text
Execute tasks/TASK-XXX.md
```

Each `tasks/TASK-XXX.md` now links to `harness/AGENT-ENTRY-INSTRUCTIONS.md`, which contains the standard status checks, harness usage, source document reading rules, verification, commit/PR flow, and final report expectations.
